Кдасс Employee содержит информацию о сотруднике: имя, зарплата, дата приема.
Integer.compare() - метод для сравнения чисел (годов, месяцев, дней).

Класс Manager содержит информацию о руководителе: имя, зарплата, дата приема, подразделение. Также содержит статический метод для повышения зарплаты сотрудникам, кроме руководителей.
Класс наследует поля и методы класса Employee. Метод instanceof используется для фильтрации руководителей.

Класс Main - основной класс программы: создание сотрудников, руководителей, повышение зарплаты, работа компаратора дат.
